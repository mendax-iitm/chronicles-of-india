# Seeded `good-first-issue` Ideas (Community Roadmap)

These 40 self-contained tasks are ideal first contributions toward our long-term goal of ~200 territorial snapshots and rich regional place coverage. Each item requires **primary or scholarly citations** in `docs/SOURCES.md` (no NC/SA restricted sources).

---

## How to Claim an Issue

1. Pick an item above and open a GitHub issue referencing its number.
2. Add or edit entries in `data/snapshots.json`, `data/places.json`, and `docs/SOURCES.md`.
3. Run `npm test` to validate schemas, atom overlaps, and Playwright checks before opening a PR.
